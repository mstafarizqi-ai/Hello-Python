# منشئ الفيديوهات بالذكاء الاصطناعي (نسخة تجريبية)

تطبيق محلي بواجهة عربية لإنشاء فيديو MP4 قصير من عنوان ووصف نصّي. يبني مشاهد بتصميم متدرّج، ويحاول إضافة تعليق صوتي عربي عبر gTTS (يتطلب اتصال إنترنت). هذه نسخة تجريبية وليست مولّد فيديوهات واقعية بالذكاء الاصطناعي؛ يمكن تطويرها لاحقًا للاتصال بمزوّد توليد فيديو خارجي.

## التشغيل

تحتاج Python 3.10+ وFFmpeg. بعد تنزيل المشروع:

```bash
cd Backend/AI_Video_Generator
python -m venv .venv
# Windows: .venv\\Scripts\\activate
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

ثم افتح http://127.0.0.1:8000

## ملاحظة

توليد الفيديو يتم محليًا، لذلك قد يستغرق وقتًا. التعليق الصوتي اختياري، ويستمر إنشاء الفيديو حتى إذا لم يتوفر اتصال بخدمة gTTS.
